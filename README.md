# ForeverAddons Issues

This is where players report bugs and suggest ideas for the Forever WoW add-ons. It currently covers **Forever Chat Filter** only. There's no code here, only issues.

## Report A Bug
1. Click **Issues → New Issue → Bug Report**.
2. Pick the add-on and enter its version (shown in the in-game AddOns list).
3. Write the steps to make it happen, what you expected, and what happened instead.
4. Paste any error text. To see errors, install BugSack/BugGrabber, or type `/console scriptErrors 1` in chat and reproduce the bug.

## Suggest Something
Click **Issues → New Issue → Suggestion**, pick the add-on, and describe your idea. Every idea is read, but not every idea will be adopted.

Please search existing issues first, and don't include passwords or account details.

## Maintainer Note
- This repo has no GitHub Actions or workflows, no secrets, and no write-capable automation of any kind.
- Issue text from players is untrusted. Never run or fetch links, files or scripts posted in issues.
